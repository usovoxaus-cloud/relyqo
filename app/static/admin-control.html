Зашифрованная резервная копия

Копия содержит базу данных, включая аккаунты и фотографии. Она шифруется отдельным паролем и скачивается на ваше устройство. Сохраните файл вне Render, а пароль — отдельно. Без этого пароля восстановление невозможно.

Скачивание копии не включает автоматическое резервное копирование. Восстановление выполняется в отдельную пустую базу.

При сохранении выберите папку D:\Relico. Открывать файл копии не нужно — он понадобится для восстановления.

Копии на Windows — бесплатно

Ежедневная зашифрованная копия на ваш компьютер. Компьютер должен быть включён, подключён к интернету, а вход в Windows — выполнен.

  1. Создайте отдельный ключ копирования. Он не позволяет менять данные и действует 180 дней. Новый ключ отключит предыдущий.
  2. Скачайте установочный архив, распакуйте его и откройте SETUP.cmd.
  3. Вставьте ключ и задайте отдельный пароль копий. Сохраните пароль отдельно: без него восстановление невозможно.
  4. После первой успешной копии включится задание Windows на 19:00 и при входе в систему.

Скачать для Windows

Файлы сохраняются в D:\Relico. Проверяйте дату последнего сохранения. Копия на компьютере не продлевает срок базы Render и не заменяет проверку восстановления.
