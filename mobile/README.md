# RELYQO для Android и iPhone

Общий проект React Native / Expo Router. Нативное меню, QR-сканер, запрос разрешения на камеру, безопасные области экрана, кнопка «Назад», русский и узбекский интерфейс. Поиск по Узбекистану, отзывы, кабинет и восстановление доступа работают с действующим `https://relyqo.onrender.com` в одной WebView. Сессия сохраняется между разделами. Права администратора проверяет существующий сервер.

Это **первая тестовая версия**, а не публикация в Google Play / App Store. Идентификатор `uz.relyqo.mobile.preview` намеренно отделён от будущей магазинной версии.

## Получение Android APK

В GitHub Actions откройте успешный запуск **Mobile app** и скачайте артефакт **RELYQO-Android-preview**. Распакуйте ZIP и откройте `RELYQO-Android-preview.apk` на Android. APK содержит JavaScript внутри, не требует Metro, компьютера или Expo Go. Интернет нужен для данных и аккаунта.

Сборка использует Release с тестовой подписью из стандартного шаблона Expo. Она не отладочная, но эта публичная тестовая подпись **не подходит для магазина или постоянного распространения**. Для магазина потребуется отдельный закрытый ключ, постоянный production application ID и увеличение versionCode. Не публикуйте ключи подписи в репозитории.

## iPhone / iPad

Этот же исходный код собирается в iOS-приложение. CI компилирует Release для симулятора и прикладывает `RELYQO-iOS-simulator`. **Это не IPA для установки на телефон.** Для TestFlight / App Store нужны аккаунт Apple Developer владельца, подпись и запись приложения в App Store Connect. CI их не создаёт и не использует чужие сертификаты.

Бесплатная проверка на личном iPhone возможна через Expo Go с запущенным `npm start` в одной сети или через Xcode на Mac с личной учётной записью Apple; она не заменяет постоянную магазинную установку. Для Android можно использовать готовый APK.

## Разработка

Node 24, npm. Android: JDK 17 и Android SDK. iOS: macOS и Xcode 26.4 или новее (CI использует 26.6). Поддерживаются Android 7+ и iOS 16.4+.

```sh
cd mobile
npm ci
npm run typecheck
npm test
npx expo export --platform android --platform ios
npx expo prebuild --platform android --no-install
cd android
./gradlew assembleRelease
```

Для iOS на Mac: `npx expo run:ios`. Для разработки на Android: `npm run android`. Сгенерированные `android/`, `ios/`, сертификаты и `node_modules/` не включаются в Git. `app.json` и lock-файл задают воспроизводимую конфигурацию. При наличии собственного Expo-аккаунта `eas build --platform android --profile preview` создаёт внутреннюю сборку; доступ к EAS для GitHub CI не требуется.

## Границы и проверки

- Только HTTPS-адрес RELYQO открывается внутри приложения. Внешние сайты, телефон и email — после подтверждения в системном приложении. `javascript:`, `file:`, `intent:` и произвольные схемы блокируются.
- Камера запрашивается при открытии сканера. Видео не пишется. При отказе можно вставить код вручную. Геолокацию запрашивает сайт при выборе карты/местоположения.
- QR проходит первичную проверку формата; подлинность, срок и однократность проверяет сервер. Код не сохраняется приложением и не передаётся в URL.
- Пароли и серверные API-ключи не помещаются в нативное хранилище или исходники. В AsyncStorage хранится только язык. Android backup отключён.
- При недоступности сервера есть повторная загрузка. Нативная оболочка не устраняет холодный запуск Render Free. Отзывы не отправляются повторно автоматически.
- Перед магазинным выпуском нужны испытания на физических Android/iPhone (камера, геолокация, выбор фото, вход/выход, восстановление), описание обработки данных, необходимые механизмы удаления аккаунта, закрытая подпись и проверка правил магазинов. Не считать симулятор проверкой физической камеры.

Изменений платного тарифа, публикации в магазинах и доступа к базе данных эта сборка не выполняет.
